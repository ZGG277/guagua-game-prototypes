# 阿莉埃蒂 1.0.3 排行榜精简候选

## 本轮改动

- 排行榜保留标题、本局最高、榜单类型/周期、自己的名次、玩家排名和返回按钮。
- 移除同步状态、规则说明、自动登记说明、刷新/重新检查按钮和重复介绍。
- 首页及游戏内排行榜入口保持可见；不可用时只展示一句“排行榜暂不可用”，不隐藏入口。
- 落回根部仍展示被冻结的本局最高记录，并自动同步成绩；打开或切换榜单不写成绩。
- 游戏物理、关卡、人物、配乐、音效、云端成绩合并、自动提交节流和不确定写入去重逻辑保持不变。
