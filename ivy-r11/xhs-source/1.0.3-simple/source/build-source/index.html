前三次成功跳跃后收起文字；箭头始终以实际下一片叶为准。亮叶可以落脚，墙面暗小叶和藤蔓仅为装饰。拖动时看虚线落点：它预测的是现在松手，再等叶面仍会滑。

接近可够到的叶缘会短暂伸手攀上；太远、太快或离开边缘仍会失手。攀缘中不能蓄力，落稳后再跳。20片后部分失误能落回下方真实路线叶；50片后逐渐变小，仍需瞄准。

起初几片较宽松，之后叶面更陡。手脚短暂攀稳后抓力减弱，会沿叶面滑下；尽快瞄准下一片。目标是第100片，没有自动跳跃或中途存档。
