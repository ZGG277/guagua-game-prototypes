**这不是找回的 1.0.3 原文件，也尚未发布。**

## 版本边界

- 已验证基础：1.0.2 源码与打包 ZIP 一致，基础 ZIP SHA-256 为 `ed15c82dd9a9c839f7be33b73903da4cb666f227e80b679c72bc7785109c61df`。
- 用户确认线上 1.0.3 已发布且没有背景音乐。原始 1.0.3 源码、分享底图和最终包在本次可用环境中未找回。

- 未发布的 1.0.4 音乐候选是另一条线，本包没有加入其代码或配乐。保留原有接取、撞击、受伤和金币音效。
- 没有覆盖基础目录，没有推送 GitHub，没有上传、预览、送审或改动线上小工具。

## 已重建功能

1. 新生成正方形宣传底图，完整树冠、木偶人物、接布和榴莲置于中央。它是近似风格的新图，不是原版图片。
2. 点击「分享本局」后合成 1080×1080 图片，接住、摔碎、被砸和净赚四项数据均来自同一份点击时快照，包含负分。
3. 文案带 `#小红书小工具 #WebCoding #小游戏 #榴莲 #榴莲刺客`。这些是正文话题文本，不声称具备未经文档支持的原生话题 ID。
4. 高光金色 SVG 硬币与闪光动画，尊重减少动态效果设置。
5. 分享图片加载失败可重试、重复点击保护、临时文件失败保护，以及重开一局时分享数据不串局。

20 颗采摘、六次半滴伤害、碎果扣 10、完整果加 20、损失音效、血滴轮廓、手势、物理和树冠逻辑继续使用 1.0.2。被砸数取去重后的 `injuryRounds.size`，不是由净剩血量推算。

## 差异与不能证明的部分

- 新底图、宣传卡尺寸与排版、SVG 硬币、具体话题拼写都是本次重建，无法证明像素或字节等同于已发布 1.0.3。
- 只有 `source/app.js` 与 `source/survival.js` 在原有 JS 模块上做相关增量；新增 `source/share-card.js`。其他原有 JS 模块逐文件哈希保持一致，见 `reports/source-differences.json`。
- 原基础的 `source/index.html`、`source/style.css` 是较早模板。本候选改以 1.0.2 实际 `dist` 的 HTML/CSS 为基线，并提升为构建输入，避免重新构建丢失已发布的界面适配。
- 非小红书网页环境可玩，但分享按钮仍提示在小红书中打开；未另加 Web Share 或下载功能。

## 构建与测试

需要 Node.js、Python 3。执行：

```sh
npm install
npm run build
npm test
npm run audit
```

`dist/` 是可运行静态网页，`durian-reconstruction-candidate.zip` 是小工具候选包。构建优先使用本项目 npm 依赖；当前云环境保留了现有依赖 fallback。可直接使用已构建 dist，重新构建不依赖线上图片资源。

已在当前云环境通过 60 项检查：机制 9 项、音效逻辑 5 项、顶部避让 24 种几何情况、整局与分享模拟 15 项、额外分享边界 7 项。源代码和构建产物均通过 JS 语法检查。已查看 Canvas 导出的实际分享图，完整角色、树、布、四项数字均可见。

独立静态审计检查根入口、脚本类型、离线资源、禁用能力、包体、ZIP 内容一致性与高消耗标记。技能自带审计脚本无法读取，因此没有声称其官方审计已运行。

## 尚未完成的验收

云容器 Chromium 启动在普通及批准的提权重试中均被 `socket() Operation not permitted` 阻断，所以浏览器 DOM 截图/布局检查未运行。已有 Canvas 图不能代替完整浏览器检查。创服平台模拟器、Android 真机扫码、iOS 真机扫码、Chrome 61、实际听音和设备性能均未验收。本候选不能凭这些模拟测试直接冒充线上原版或真机验收通过。

发布前应确认接受上述重建差异，再上传同一候选包，在创服平台模拟器、Android 和 iOS 上验证完整流程。

## 当前规范

已于 2026-11-05 获取在线小工具文档。分享仍使用公开 `writeTempFile` / `postNote`。新增的 `assets/` 静态资源优化对客户端 9.53.3 起、平台启用范围内生效；本包完整打入延迟使用的分享图片，并在加载失败时提示重试。小游戏只用 Canvas 2D，无 Worker、OffscreenCanvas、WASM、Unity 或 Cocos，故标记 `is_high_consumption_scene: false`。
