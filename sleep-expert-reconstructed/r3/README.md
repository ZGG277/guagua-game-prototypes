## 本轮行为
- 摇篮 2.6 秒自然周期，左右顶点轻点，每顶点至多一次，容错约 ±0.32 秒；提前输入在转折后施力；幅度上限 0.50。
- 先抽腿下手再抽头下手：每 3.8 秒呼吸一次，腿窗口 0.50 秒、头 0.35 秒，每口气最多推进 25% / 20%。必须松开停稳 0.25 秒，再在短窗内按下。理想两手约 33 秒。持续提前按住不能完成。
- 计时从开始到第一次深睡封存，暂停/后台仍计入实际时间。后续守睡 60 秒另算，不污染速度榜。练习/异常时钟不提交。
- 排行榜在顶部单一音乐入口旁，使用官方 board2 的负秒数；无权限、未开白名单、接口失败均显示真实状态，不造排行。
- 保留放下平衡、八种噪音干预、60 秒守睡奖章、分享、关注作者和关灯渐暗（平台未提供退出API，保留右上关闭提示）。小工具运行包使用触控，不含网页姿态感应。

## 构建和测试
需要 Node.js 与 esbuild 0.28.0。安装开发依赖后运行：

```
npm install
npm run build
npm test
```

可设 ESBUILD_BIN 指向已有官方 esbuild 二进制。源码入口在 src，模块在 dist；scripts/build.mjs 生成 classic IIFE/Chrome61 目标的 artifact/app.js。交付运行包只包含 artifact 的 index.html、style.css、app.js、mini_tool.json。无运行时网络请求、外链资源、模块脚本或传感器权限。
