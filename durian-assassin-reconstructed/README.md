# 榴莲刺客：重建候选

**这是依据 1.0.2 重建的独立候选，不是线上原始 1.0.3 源码。**

线上 1.0.3 没有背景音乐。本候选也没有背景音乐，保留接取、受伤和金币音效；未发布的 1.0.4 音乐候选不包含在这里。

## 与线上原版的区别

- 1.0.3 原始源码和分享底图未恢复。本目录依据已知需求重建功能，不能保证与线上 1.0.3 的像素、字节或行为完全相同。
- 分享底图是近似原有风格的新生成图，不是原图。分享卡的方形排版、高光金币和具体话题文案也是本次重建。
- 这是单独的目录，没有替换仓库中的旧版榴莲游戏。
- **手机尚未验收。** 创服平台模拟器、Android、iOS、Chrome 61、实际听音和设备性能均未验证。

## 内容

- 20 颗采摘、血滴耗尽结束、接住加 20 金币、碎果减 10 金币。
- 分享卡完整展示人物、接布和榴莲，并合成接住、摔碎、被砸、净赚四项本局数据。
- 分享文案包含小红书小工具、WebCoding、小游戏和榴莲话题。
- 原有 15 个 JavaScript 模块哈希未改变。变更集中在界面、结算统计和分享层。
- 普通网页中可玩；小红书分享能力仅在注入相关 API 的小红书容器中可用。

## 构建与测试

需要 Node.js 18+：

```sh
npm install
npm run build
npm test
```

`source/` 保存模块源码，`scripts/platform.js` 为平台适配层。`assets/share-hero-reconstructed.jpg` 是重建图片。构建生成 `dist/`，并同步到本目录根供 GitHub Pages 加载。构建目标为 ES2017 / Chrome 61；构建目标不等于真机兼容性已验证。

已通过 60 项检查：机制 9 项、音效逻辑 5 项、顶部避让 24 种几何情况、整局与分享模拟 15 项、额外分享边界 7 项。分享覆盖负分、被砸计数、图片失败重试、重复点击及重开时的数据快照。JS 语法检查通过，候选包静态审计无错误或警告。

已检查 Canvas 合成分享图。完整浏览器检查因测试环境无法启动 Chromium 而未完成；模拟与 Canvas 检查不代表平台或手机验收。

验收记录见 `VALIDATION.json` 和 `reports/`。后续若要发布小红书，应对同一构建产物完成创服平台模拟器及 Android / iOS 真机扫码验证。
