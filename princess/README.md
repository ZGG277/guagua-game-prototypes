# 公主请开球

暖象牙金丝桌帮、深绿绒面、暖色大理石与通透宝石球。完整8秒城堡开场后，从末帧对应机位连续推进到第一视角；右下角可以跳过。

[固定试玩](https://zgg277.github.io/guagua-game-prototypes/princess/)

拨动底部轮盘瞄准，按住右下球杆下拉蓄力，松手击球。顶部问号可重看操作引导；右上可切换全局视角与第一视角。彩球正常档82%透射，白球/黑8与珠光腰带保留。首次有声播放受浏览器规则限制时，轻触“轻触有声”。

使用用户2026-11-05验收的相同运行文件，不另改游戏。网页分享显示卡片预览；平台内原生分享由宿主提供。小红书版本状态单独记录。
