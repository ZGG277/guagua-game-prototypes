# 公主请开球

暖象牙金丝桌帮、丝绒台呢与宝石球。打开后播放约5秒城堡开场，右下角可以跳过。

试玩：https://zgg277.github.io/guagua-game-prototypes/princess/

拨动底部轮盘瞄准，按住右下球杆下拉蓄力，松手击球。顶部问号可重看操作引导；右上可切换全局视角与第一视角。首次有声播放受浏览器规则限制时，轻触“轻触有声”。

本次使用2026-11-03暖象牙与引导修正版的相同运行文件，小工具版本1.0.9；网页分享显示卡片预览，平台内的原生分享能力由宿主提供。
